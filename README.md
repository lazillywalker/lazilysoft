# LazilySoft

**Free and practical software tools for Linux users.**

LazilySoftは、Linuxをもっと身近に、もっと便利にするためのソフトウェア開発プロジェクトです。

日常業務や個人利用で役立つ、小さくても実用的なツールの開発を目指しています。

LazilySoft is an independent software development project focused on creating practical and easy-to-use tools for Linux users.

Our goal is to make Linux more convenient for everyday work and personal use.

---

## Software / ソフトウェア一覧

### LazilyFAX
**Linux FAX Utility**

Linux環境でFAXを送信するためのソフトウェアです。

- PDFファイルからのFAX送信
- 送信前のプレビュー
- 電話帳管理
- 送信履歴管理
- 日本語・英語・韓国語対応

A Linux fax utility featuring PDF transmission, document preview, contact management, transmission history, and multilingual support.

**Status:** Under development / 開発中

### LazilyCapture
**Linux Screenshot Utility**

画面全体、ウィンドウ、指定範囲を簡単に撮影するためのGUIツールです。

A simple screenshot utility for capturing full screens, application windows, and selected areas.

**Status:** Planned / 開発予定

### LazilyGreeting
**Smart Greeting Utility**

古いAndroid端末などを再活用し、人の検知や時間帯に応じた挨拶を行うソフトウェア構想です。

A planned greeting application designed to reuse older Android devices.

**Status:** Concept / 構想段階

## Development Policy / 開発方針

- Practical software / 実用性を重視
- Simple operation / 簡単な操作
- Lightweight design / 軽量な設計
- Reuse existing hardware / 既存機器の再活用
- Affordable and accessible tools / 利用しやすいソフトウェア

## Supported Platforms / 対応環境

主にLinux Mintを使用して開発・検証しています。

Development and testing are primarily performed on Linux Mint.

Other Linux distributions may be supported depending on the application.

## Distribution / 配布について

無料ソフトウェアはGitHubなどを通じて公開する予定です。

一部のソフトウェアでは、追加機能を備えた有料版を提供する場合があります。

Free utilities will be distributed through GitHub and other platforms. Some applications may also offer paid editions with additional features.
